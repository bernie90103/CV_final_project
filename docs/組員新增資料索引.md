## 核對結果

本機已核對兩份 `mean_std.csv`：都是 81 列，條件鍵相同，資料集與研究程式的雜湊也相同。各列 AUPRO@0.3 平均值的最大差距約為 **0.0000224**。原有的九個科學測試，以及隊員新增的十三個延伸指標測試，均通過。這支持 Colab 摘要對原實驗的重現；GitHub 沒有收錄完整的 Colab 執行資料夾，因此本索引不把那 81 份原始輸出當成已在儲存庫內驗證。

Colab 使用不同的 GPU、CPU 與執行環境。**準確度表可以對照，延遲不要直接合併或比較。**新分析中的 `pixel_f1max_oracle` 會用測試 mask 選門檻，只能作為診斷，不能當成沒有測試資料調參的部署成績。`metal_nut` 的小瑕疵只有七張異常圖，`screw` 的較大瑕疵只有一張；這兩組的細小差異不宜作強推論。

## 建議閱讀順序

第一次看專案，先讀根目錄 `README.md`、正式 PDF 與 `docs/實作與執行指南.md`。想理解隊員新增了什麼，再讀 `colab_rerun/README.md`，依序看 `results/summary/mean_std.csv`、`results/extended/claims.csv` 和對應的詳細表。若要修改正式報告，先挑出要新增的結論，確認其指標定義、樣本數與比較條件，再同步更新英文 PDF、Word 和投影片；目前這些交件檔案尚未整合延伸指標。
